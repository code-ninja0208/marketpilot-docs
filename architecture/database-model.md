# Database model v1 (MVP)

PostgreSQL 18. Conventions:

- Primary keys `id uuid` (UUIDv7, generated by the application). Timestamps `timestamptz`, UTC.
- Every tenant-owned table has `org_id uuid not null references organizations(id)` (review B7)
  and an index starting with `org_id`. Repository functions take `orgId` first.
- `created_at` / `updated_at` on every table (omitted below). Soft delete only where stated.
- Enumerations are `text` columns with `CHECK` constraints (easier to evolve than PG enums).
- `version int not null default 1` = optimistic concurrency; updates use `WHERE version = $expected`.

Review fixes included: B1 `placement_key`, B2 lease columns, B3 `idempotency_keys`,
B4 `ai_generations`, B5 `invitations`, B6 `oauth_states`, B7 `org_id` everywhere, B8 `media_assets`,
B11 `comments`, B13 `usage_reservations`.

## 1. Identity and tenancy (W2)

**users**: `id`, `auth_subject text unique not null` (JWT `sub`), `email citext not null`,
`display_name text`, `last_seen_at`.

**organizations**: `id`, `name text not null`, `slug text unique not null` (`^[a-z0-9-]{3,40}$`),
`require_separate_reviewer bool not null default false` (review F3), `deleted_at` (soft delete).

**memberships**: `id`, `org_id`, `user_id → users`, `role text check (owner|admin|editor|reviewer)`,
`status text check (active|suspended)`. Unique `(org_id, user_id)`. Invariant (service-enforced,
tested): every organization keeps at least one active owner.

**invitations**: `id`, `org_id`, `email citext`, `role`, `token_hash bytea unique` (SHA-256 of the
emailed token; the token itself is never stored), `invited_by → users`, `expires_at`,
`accepted_at`, `revoked_at`. Partial unique `(org_id, email) where accepted_at is null and revoked_at is null`.

**platform_staff**: `id`, `user_id unique → users`, `role text check (support|operator|superadmin)`,
`mfa_required bool default true`. Separate from memberships (review E4): customer roles never grant staff access.

**audit_events**: `id`, `org_id` (nullable for platform-level events), `actor_user_id`,
`actor_type text check (user|staff|system)`, `action text` (e.g. `membership.role_changed`),
`resource_type`, `resource_id uuid`, `metadata jsonb` (no secrets), `request_id text`.
Append-only: the application role has no `UPDATE`/`DELETE` grant on this table.

## 2. Business configuration (W3)

**businesses**: `id`, `org_id`, `name`, `industry text check (real_estate|sales|ecommerce|general)`,
`timezone text` (IANA, validated), `status text check (active|archived)`.

**brand_profiles**: `id`, `org_id`, `business_id unique`, `tone text`, `audience text`,
`restrictions jsonb` (words/claims never to use), `version`.

**brand_facts** (approved facts the AI must cite): `id`, `org_id`, `business_id`,
`kind text check (price|hours|address|offer|service|claim|other)`, `label`, `value text`,
`valid_from`, `valid_until`, `verified_by → users`, `verified_at`.

**listings** (real estate): `id`, `org_id`, `business_id`, `address`, `price_amount numeric(14,2)`,
`price_currency char(3)`, `bedrooms int`, `bathrooms numeric(3,1)`, `area_sqm numeric`,
`features jsonb`, `status text check (draft|active|under_offer|sold|withdrawn)`.

## 3. Strategy and campaigns (W4)

**marketing_strategies**: `id`, `org_id`, `business_id`, `name`, `audience_segment text`,
`channels text[]`, `assumptions jsonb`, `status text check (draft|active|archived)`.

**marketing_objectives**: `id`, `org_id`, `strategy_id`, `metric text` (e.g. `inquiries`),
`target_value numeric not null`, `due_date date not null`, `baseline_value numeric`.
An objective is measurable only with metric + target + date (W4-2).

**campaigns**: `id`, `org_id`, `business_id`, `objective_id`, `title`,
`status text check (draft|active|completed|archived)`, `starts_on date`, `ends_on date`
(`check ends_on >= starts_on`), `created_by`.

**campaign_briefs**: `id`, `org_id`, `campaign_id unique`, `description`, `audience`,
`call_to_action`, `listing_id` (nullable), `fact_ids uuid[]`.

**idempotency_keys**: `org_id`, `key text`, `request_hash bytea`, `status text check
(in_progress|completed)`, `response_status int`, `response_body jsonb`, `expires_at`.
Primary key `(org_id, key)`. Same key + same hash → replay; same key + other hash → 409.

## 4. AI and usage (W5)

**ai_generations**: `id`, `org_id`, `campaign_id`, `status text check (queued|running|succeeded|failed)`,
`input jsonb`, `output jsonb`, `reservation_id`, `credits_used int`, `error_code text`.

**usage_reservations**: `id`, `org_id`, `resource text` (e.g. `ai_credits`), `amount int`,
`status text check (reserved|settled|released)`, `expires_at`.

**usage_events**: `id`, `org_id`, `resource`, `quantity int`, `unit_cost_usd numeric(12,6)`,
`period text` (`YYYY-MM`), `source_id uuid`. Index `(org_id, resource, period)`.

## 5. Content (W6)

**content_drafts**: `id`, `org_id`, `campaign_id`, `platform text`, `status text check (active|archived)`.

**content_revisions**: `id`, `org_id`, `draft_id`, `revision_no int`, `body text`,
`media_asset_ids uuid[]`, `generation_id` (nullable), `created_by`. Unique `(draft_id, revision_no)`.
Immutable: never updated after insert.

**media_assets**: `id`, `org_id`, `business_id`, `storage_key text unique`, `mime_type`,
`size_bytes bigint`, `width int`, `height int`, `checksum_sha256 bytea`,
`status text check (pending_upload|ready|rejected)`.

**comments**: `id`, `org_id`, `resource_type text check (campaign|draft|post_target)`,
`resource_id uuid`, `author_id`, `body text`, `deleted_at`.

## 6. Publishing (W7–W10)

**post_targets**: `id`, `org_id`, `draft_id`, `social_account_id`, `placement_key text` (B1),
`state text` (states of `packages/domain` publication state machine), `approved_revision_id`,
`scheduled_at`, `external_post_id`, `external_url`, `lease_owner text`, `lease_expires_at`,
`fencing_token bigint not null default 0` (B2), `version`.
Unique `(draft_id, social_account_id, placement_key)`. Index `(state, scheduled_at)` for dispatch.
Tenant consistency: the social account must belong to the same business as the draft's campaign
(service check + composite foreign key on `(org_id, business_id)`).

**approvals**: `id`, `org_id`, `target_id`, `revision_id`, `reviewer_id`,
`decision text check (approved|rejected)`, `reason text`, `invalidated_at`.
Partial unique `(target_id) where decision = 'approved' and invalidated_at is null`
→ at most one effective approval (APP-02).

**publish_attempts**: `id`, `org_id`, `target_id`, `attempt_no int`, `fencing_token bigint`,
`started_at`, `finished_at`, `outcome text check (success|transient_error|definitive_error|unknown)`,
`provider_request_id`, `external_container_id`, `error_code`. Unique `(target_id, attempt_no)`.
An attempt with `started_at` and no `finished_at` after its lease expired → reconciliation.

**outbox_events**: `id`, `org_id`, `event_type`, `aggregate_id`, `payload jsonb`, `processed_at`.
Index `(processed_at) where processed_at is null`.

**metric_snapshots**: `id`, `org_id`, `target_id`, `captured_at`, `impressions int`, `reach int`,
`engagements int`, `clicks int`. Index `(target_id, captured_at)`.

## 7. Integrations (W8)

**social_accounts**: `id`, `org_id`, `business_id`, `provider text check (facebook|instagram)`,
`external_account_id`, `display_name`, `token_ciphertext bytea`, `token_key_id text`,
`token_expires_at`, `status text check (active|reconnect_required|disconnected)`.
Unique `(business_id, provider, external_account_id)`.

**oauth_states**: `state_hash bytea primary key`, `org_id`, `business_id`, `user_id`, `provider`,
`pkce_verifier_ciphertext bytea`, `expires_at`, `used_at`. Single use: `used_at` set atomically.

## 8. Billing (W11)

**subscriptions**: `id`, `org_id unique`, `plan text check (free|starter|growth|business)`,
`status text`, `stripe_customer_id unique`, `stripe_subscription_id unique`, `current_period_end`.

**webhook_events**: `id`, `provider`, `external_event_id`, `status text check (received|processed|failed)`,
`processed_at`. Unique `(provider, external_event_id)` (PAY-01).

**system_flags**: `key text primary key` (e.g. `publishing_paused`), `value jsonb`, `updated_by`.
Read by the worker before every publish (W11-4 kill switch).

## Not in v1 (later phases)

Contacts, consents and suppressions (email, review B12), agency grants (F2), research sources
(G2), leads and pipelines (sales module), products and stores (ecommerce module), conversations.
